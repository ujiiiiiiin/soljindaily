한솔유진 부부 캘린더 - 미리보기 실행 방법

[처음 한 번만]
1. 컴퓨터에 Node.js를 설치합니다.
2. 이 폴더를 압축 해제합니다.
3. 폴더 안에서 주소창에 cmd 를 입력하고 Enter를 누릅니다.
4. 검은색 창에 아래 두 줄을 차례대로 입력합니다.

   npm install
   npm run dev

5. 화면에 http://localhost:5173 같은 주소가 나오면 Ctrl+클릭합니다.
6. 브라우저에서 앱 화면이 열립니다.

[다음부터]
폴더에서 cmd를 열고 아래만 입력하면 됩니다.

   npm run dev

[종료]
검은색 창에서 Ctrl + C

참고:
- 이 미리보기 버전은 원본의 window.storage 저장 기능을 브라우저 localStorage로 연결해 놓았습니다.
- 따라서 일정/설정 등의 테스트 데이터가 브라우저에 저장됩니다.
- 실제 배포용 앱을 만드는 단계에서는 저장 방식과 사진 저장 방식 등을 별도로 정리하면 됩니다.
